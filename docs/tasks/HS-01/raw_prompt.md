# 01 — Skeleton and deploy

Hopscore is a brand-new web app, so there is nothing yet. This task sets up the project so every later task has a place to land and a live URL to check on a phone.

Goal:
1. A TypeScript web app built with Vite, with Three.js and Vitest added as dependencies.
2. A test command that runs (one trivial test is fine) and a build command that produces static files.
3. A GitHub Actions workflow that runs the tests and then deploys the build to GitHub Pages on every push to `main`.
4. A placeholder page titled "Hopscore", with the tagline "Dixit Score Tracker", that works in portrait on a phone.
5. A short README: what the app is, how to run it, how to test it, how it deploys.

Keep the folder layout simple and obvious. Leave clear homes for: scoring logic, storage, screens, and the 3D board.

Done when: the page is live on GitHub Pages, and opening it on a phone shows the title and tagline.

**Depends on:** nothing.

See full architecture plan: docs/plan/spec.md
